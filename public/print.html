Set up silent printing (do this once on the laptop)

Without this, Chrome shows a print dialog for every slip and someone has to click Print. With it, slips just come out.

  1. Install Star's macOS driver for the TSP100 (star-m.jp, "TSP100 futurePRNT" or "Star CUPS driver"), plug the printer in by USB and add it in System Settings › Printers & Scanners. Print a test page from there.
  2. Quit Chrome completely (Chrome menu › Quit).
  3. Open the Terminal app and paste this (one line), then press Return: 
    
            This opens a separate Chrome window just for printing, so your normal Chrome isn't affected.

  4. Before the kiosk window, set Chrome's print choices once, because silent printing reuses them. Open this page in that Chrome profile without the kiosk switch (same command without --kiosk-printing), press Test print, and in the dialog:
            
      
              
    • Destination: the Star TSP100
      • 
              
    • Layout: Portrait
      • 
              
    • Under More settings: Paper size a 72 mm size (e.g. "72mm x 200mm" or "72mm x Receipt"), Margins: None, Scale: Default, and Headers and footers unchecked (this is what prints the date and web address)
      • 
            
    
            Print. The slip should come out upright with nothing at the top or bottom. Quit that window, then run the command above (with --kiosk-printing).
    5. 
          
  5. If it still comes out sideways, open System Settings › Printers & Scanners › TSP100 › Options (or the driver's utility) and make the default paper a 72 mm receipt size, not Letter.
    6. 
          
  6. From then on Test print prints with no dialog. Leave the window open (not minimized) during the event, and keep the laptop plugged in with sleep turned off.
